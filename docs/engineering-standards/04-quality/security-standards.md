# 安全开发规范

## 目标

定义研发侧安全基线，降低认证授权、OAuth、OIDC、密钥管理、个人信息、输入校验、数据保护、安全日志和依赖安全风险。

## 适用范围

适用于所有处理用户数据、业务数据、内部系统数据、外部接口、身份认证、权限控制、生产运行信息和第三方集成的软件项目。

## 规范要求

- 认证与授权决策必须在可信后端或服务端边界执行，不得只依赖前端隐藏按钮、页面路由或客户端判断。
- 使用 OAuth、OIDC 或企业统一身份服务时，必须校验签名、签发方、受众、过期时间、授权范围和回调地址。
- 密钥、令牌、密码、证书私钥和生产凭据不得提交到仓库、构建日志、测试夹具、截图、文档示例或聊天记录。
- 所有跨信任边界的输入必须校验，包括 HTTP 请求、文件上传、消息队列、回调通知、URL 参数、本地存储、第三方 SDK 返回值和用户输入。
- 个人信息和敏感业务数据必须按最小必要原则采集、使用、展示、传输、存储和删除。
- 日志、错误响应、导出文件、测试数据和排障材料不得泄露密钥、令牌、完整个人信息和原始敏感载荷。
- 安全相关事件必须记录主体、动作、对象、结果、时间和必要上下文。
- 依赖漏洞必须按可利用性、暴露面和业务影响确定优先级，并形成修复或缓解处理。

## 认证与授权

认证用于确认调用方身份，授权用于判断调用方能否执行某个操作。两者必须在可信边界执行。涉及越权风险的接口必须验证用户、角色、租户、组织、资源所有权和操作范围。

OAuth 和 OIDC 集成必须使用受信任的授权服务器和受控客户端配置。回调地址必须固定或白名单控制。访问令牌、刷新令牌和授权码不得暴露到日志、URL 长期存储、浏览器不安全存储或第三方脚本可访问位置。

服务之间调用必须明确身份传递方式、权限边界和审计字段。不得把内部服务调用视为天然可信。

## 密钥与敏感信息

密钥包括密码、API key、Token、证书私钥、数据库连接串、云服务凭据、Webhook secret 和生产运维凭据。密钥必须来自受控密钥管理服务、部署平台安全变量或受控配置中心。

个人信息包括身份证号、手机号、邮箱、地址、定位、设备标识、生物特征、支付信息以及可识别个人身份的组合数据。个人信息必须最小化采集，展示和日志必须脱敏，导出和共享必须受控。

密钥轮换、泄露处置和访问审计必须具备明确责任人和操作记录。发现密钥进入仓库或日志时，必须立即撤销、轮换并评估影响范围。

## 输入校验

输入校验必须覆盖类型、格式、长度、范围、必填字段、枚举值、文件类型、文件大小、业务约束和权限边界。不得依赖前端校验或数据库约束作为唯一保护。

文件上传必须校验大小、类型、内容特征、存储位置、访问权限和安全扫描结果。回调通知必须校验来源、签名、时间窗口和幂等键。

输入校验失败必须返回稳定错误响应，不得暴露内部实现、SQL、堆栈和敏感值。

## 数据保护

敏感数据传输必须使用受保护通道。存储敏感数据时，必须根据数据等级采用加密、脱敏、访问控制、审计和生命周期管理。

测试、排障、数据分析和培训材料不得直接使用未脱敏生产数据。确需访问生产样本时，必须完成授权、脱敏、隔离和销毁控制。

数据导出必须限制范围、记录用途、记录操作者、设置访问边界，并按数据等级控制保留时间。

## 安全日志与审计

安全日志必须记录 actor、action、target、result、time、source 和必要 context。日志不得记录敏感明文。审计日志应当防止被普通业务流程随意修改或删除。

登录、登出、权限变更、密钥访问、数据导出、敏感配置变更、生产数据修复、批量操作和安全拒绝必须产生审计记录。

## 依赖安全

依赖漏洞必须按以下因素评估：是否可被远程利用，是否暴露在公网或不可信输入路径上，是否影响认证授权、数据保护、远程代码执行或权限提升，是否已有利用代码，是否存在补丁、缓解措施或替代依赖。

高风险漏洞必须制定修复或缓解计划，并说明验证方式。无法立即升级时，必须提供隔离、配置缓解、功能关闭或访问限制方案。

## 常见反模式

- 只在前端控制按钮显示，不在后端做权限校验。
- 密钥出现在仓库、日志、截图或文档示例中。
- 接口直接信任客户端提交的用户、角色、租户或价格。
- 日志记录完整身份证号、手机号、令牌或密码。
- 上传文件只看扩展名，不限制内容类型和大小。
- OAuth 或 OIDC 集成不校验签发方、受众和回调地址。
- 依赖漏洞报告长期无人处理。

## 检查清单

- 认证与授权是否在可信后端边界执行？
- OAuth、OIDC 集成是否校验签名、签发方、受众、过期时间和授权范围？
- 仓库、日志、测试数据和文档中是否排除了密钥？
- 所有信任边界输入是否完成输入校验？
- 个人信息是否最小化、脱敏并受保护传输？
- 安全日志是否包含主体、动作、对象、结果和时间？
- 依赖漏洞是否按风险优先级处理？
