# CI/CD And Release

## When To Load

Load this index when a task touches CI/CD pipeline, workflow, build job, quality gate, deployment, environment promotion, versioning, release plan, rollback, release verification, or release notification.

- `docs/engineering-standards/05-delivery-and-operations/ci-cd-and-release.md`
