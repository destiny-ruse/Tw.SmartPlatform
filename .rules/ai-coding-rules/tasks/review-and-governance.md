# Review And Governance

## When To Load

Load this index when a task touches code review, architecture review, quality metrics, governance responsibility, exception handling, high-risk change analysis, or engineering standard compliance.

## Required Formal Standards

- `docs/engineering-standards/06-governance/review-and-governance.md`
- `docs/engineering-standards/02-collaboration/code-review.md`
- `docs/engineering-standards/01-foundation/terminology-and-exceptions.md`

## Execution Requirements

- Read the formal review and governance standard before reviewing or proposing high-risk changes.
- Identify correctness, security, compatibility, observability, testing, rollback, and operational impact.
- Record exceptions with rule, reason, risk, owner, mitigation, reviewer, and review date.
